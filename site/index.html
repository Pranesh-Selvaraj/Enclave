Security model

There is no server to breach.

There is no backend to trust, no account to leak and no relay that sees your notes. The only copy of your key is the one derived on your device.

Read the security model

The vault on disk

Every page, block, search index and embedding lives inside one encrypted SQLCipher database. Keys are stretched with Argon2id before anything is opened.

  • SQLCipher AES-256-CBC + HMAC-SHA512
  • Argon2id 64 MiB, 3 passes, 4 lanes
  • BIP39 12-word recovery phrase

On the wire

Peers find each other only on the local network. A challenge-response handshake proves both sides hold the same vault-derived key; then every frame is sealed.

  • mDNS local discovery, no directory
  • WebSocket device-to-device transport
  • XChaCha20-Poly1305 authenticated frames

Updates you approve

Enclave never checks for updates unless you turn it on. Each update is shown with its changelog and must be downloaded and verified before the installer can run.

  • Opt-in no background update checks
  • SHA-256 artifact digest
  • Ed25519 pinned release key

Nothing phones home

No account, no analytics, no crash reporting and no license check. The optional assistant contacts only the endpoint you configure — or nothing at all.

  • No account no identity server
  • No telemetry no analytics SDK
  • No relay data stays on your network

Roadmap

The next Enclave is being built in the open.

No dates dressed up as deadlines. Each phase ends when its exit criteria are met, and the stable release stays supported while the native apps land.

  • Versioned contract
  • Native Android slice

In progress

Android, release-ready.

The Compose app runs on the same Rust core as the desktop app. The remaining work is confidence, not a rewrite.

  • Real-device pass: widgets, background sync, share target, backup and restore.
  • Cross-editor parity with the web editor, including tables, tasks and marks.
  • Instrumented tests for the vault flow and the widget cache.
  • The last settings gaps and the polish pass on the primary screens.

Exit criteria

A published parity checklist, background sync measured on a real phone, and a TalkBack pass on the primary flows.

Decision gate

A native desktop, with no browser engine.

Once the desktop stack gate closes, the native shell follows on the same core — with the platform integration a webview cannot give.

  • Vault flow, sidebar, editor, whiteboard, databases, graph and split view.
  • Command palette, settings, tray and wallpaper widgets.
  • Native menus, file dialogs, drag-and-drop and notifications.
  • Signed installers and verified updates on Linux, Windows and macOS.

Exit criteria

Feature parity with the desktop Tauri app, a screen-reader and keyboard-only pass, and signed updates verified on all three OSes.

Criteria-gated

Two native apps, one vault.

Parity is proven by interop tests, not manual demos. The native apps ship alongside the Tauri app until every surface matches, then the webview shell is retired.

  • The cross-app interop matrix in CI: Tauri ↔ native Android ↔ native desktop.
  • Release pipelines for both native apps: signing, versioning, changelog.
  • Vault migrations tested against every released fixture.
  • Retire Tauri only when the parity checklist is green.

Exit criteria

A v1.13 vault opens in both native apps, syncs with an unmodified Tauri app, and the Tauri app can be removed without losing features or data.

Deliberately not planned

iOS is not in this plan, though the versioned contract is designed not to preclude it. There is no cloud relay, account or telemetry, no shared UI framework between the apps, and no rewrite of the vault, crypto or sync protocol.

Questions

Answers, before you trust us with your notes.

The short version: no server, no account, no telemetry. If something here is still unclear, the full documentation is in the repository.

Does Enclave need an internet connection?

No. Creating, editing and searching work entirely offline. Sync uses your local Wi‑Fi. The optional assistant can use a local endpoint that never touches the internet, and update checks are strictly opt-in.

Where are my notes stored?

In one encrypted SQLCipher vault on your device. Backups are still-encrypted snapshots, and there is no server that holds a copy. The desktop app can export Markdown and HTML when you want a portable copy.

What happens if I forget my password?

Use the 12-word BIP39 recovery phrase you saved when the vault was created. If both the password and the phrase are lost, the vault cannot be decrypted — there is no recovery server, by design.

Can I sync more than two devices?

Yes. Devices on the same network discover each other over mDNS and authenticate with the vault-derived sync key. If your network blocks mDNS, add a peer manually by address from the sidebar.

Is Enclave really open source?

Yes, MIT licensed. The code, decision records and security model are in the repository, and you can build from source. The website itself is a static page with no analytics.

Why is Android still beta?

The native Android app is part of the move away from the old webview shell. It builds, signs and runs the same encrypted core, but real-device sync, widgets and a TalkBack pass are still tracked as open work.
