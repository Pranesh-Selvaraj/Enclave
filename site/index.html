Why Enclave

Private by default. Useful by design.

Encryption is not a setting you turn on. It is the shape of the app — from the database file to the frames travelling across your Wi-Fi.

Local-first, always

Create, edit and search with the network switched off. Every note lives on your device first; sync is an enhancement, never a requirement. No login, no subscription, no outage that can lock you out of your own notes.

Encrypted at rest

The entire vault — pages, blocks, search index and embeddings — sits inside one SQLCipher database. The key is derived from your password or 12-word recovery phrase and never leaves the device.

Sync without a server

Devices on the same Wi-Fi discover each other over mDNS and sync directly over WebSocket. Peers prove they hold the same vault key, every frame is sealed, and conflicts resolve per document. No relay, no cloud routing.

A real editor

Rich blocks, slash commands, tables and typed databases, callouts, toggles, page links, backlinks, split view and an editable Markdown source. Everything round-trips through the same encrypted document model.

Canvas and connections

An infinite whiteboard with sticky notes, shapes, connectors, frames and mind maps — plus a graph view that shows how your pages link together. Export a canvas to PNG when you need to share it.

AI on your terms

The assistant is opt-in and talks only to the endpoint you configure: a local Ollama, llama.cpp, LM Studio, vLLM — or an API you choose. Embeddings can run fully offline inside the app.

Security model

There is no server to breach.

There is no backend to trust, no account to leak and no relay that sees your notes. The only copy of your key is the one derived on your device.

The vault on disk

Every page, block and index is stored in an encrypted SQLCipher database. Keys are stretched with Argon2id before anything is opened.

  • SQLCipher AES-256-CBC + HMAC-SHA512
  • Argon2id 64 MiB, 3 passes, 4 lanes
  • BIP39 12-word recovery phrase

On the wire

Peers find each other only on the local network. A challenge-response handshake proves both sides hold the same vault-derived key; then each frame is sealed.

  • mDNS local discovery, no directory
  • WebSocket device-to-device transport
  • XChaCha20-Poly1305 authenticated frames
  • LWW per-document merge

Updates you approve

Enclave never checks for updates unless you turn it on. Each update is shown with its changelog and must be downloaded and verified before the installer can run.

  • Opt-in no background update checks
  • SHA-256 artifact digest
  • Ed25519 pinned release key

Nothing phones home

There is no account, no analytics, no crash reporting and no license check. The optional assistant contacts only the endpoint you configure — or nothing at all.

  • No account no identity server
  • No telemetry no analytics SDK
  • No relay data stays on your network

Security is a maintained surface, not a launch feature. The full model, the threat boundaries and the private reporting process are documented in the repository.
