# Desktop icon assets

These are the platform icon files used by the desktop packaging/signing work. They were originally generated from the brand vectors in `docs/brand/` and are kept here so the native desktop does not depend on the retired Tauri tree.

Source of truth: the SVG files in [`docs/brand/`](../../../../docs/brand/README.md). Regenerate the `.ico`/`.icns`/PNG set when the mark changes; do not hand-edit the binaries.
